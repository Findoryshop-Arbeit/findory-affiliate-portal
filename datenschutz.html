Grundsatz

Findory ist aktuell als statische Website ohne eigene Analyse-, Marketing- oder Newsletter-Tracking-Dienste konzipiert. Es werden keine eigenen Nutzerprofile zu Werbezwecken erstellt.

Hosting und Server-Logs

Diese Website wird über GitHub Pages ausgeliefert. Beim Besuch einer GitHub-Pages-Website wird die IP-Adresse laut GitHub zu Sicherheitszwecken protokolliert. Weitere Informationen zur Verarbeitung durch GitHub findest du in der GitHub-Datenschutzerklärung.

Kontaktaufnahme

Wenn du per E-Mail Kontakt aufnimmst, verarbeiten wir die übermittelten Angaben zur Bearbeitung deiner Anfrage. Die Daten werden gelöscht, sobald die Anfrage abschließend bearbeitet ist und keine gesetzlichen Aufbewahrungspflichten entgegenstehen.

Speicherungen im Browser

Der aktuelle Datenschutzhinweis verwendet ausschließlich eine lokale Browser-Speicherung, damit der Hinweis nach Bestätigung nicht bei jedem Seitenaufruf erneut erscheint. Es werden dabei keine Nutzungsprofile übertragen.

Die derzeit sichtbaren Beispielbilder werden von Unsplash geladen. Beim Aufruf kann dein Browser daher eine Verbindung zu Unsplash herstellen. Es sind aktuell keine Affiliate-Links aktiv. Vor der Aktivierung von Affiliate-Links oder weiteren externen Diensten wird diese Erklärung aktualisiert.
